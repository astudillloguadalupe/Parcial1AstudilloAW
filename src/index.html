Estructura con significado

HTML5 permite organizar el documento mediante elementos semánticos que indican la función de cada bloque de contenido.

En esta página se utilizan <header>, <nav>, <main>, <section>, <article> y <footer> para construir una estructura clara.

Cada elemento aporta significado a la estructura del documento y facilita su interpretación por navegadores, lectores de pantalla y motores de búsqueda.

02 / CSS

Modelo de caja

Las dos cajas tienen el mismo width, padding y border. La diferencia está en cómo CSS calcula el tamaño final.

Comportamiento por defecto

Content-box

width: 300px

padding: 30px

border: 5px

300 + 60 + 10 = 370px

Ancho final: 370px

Modelo alternativo

Border-box

width: 300px

padding: 30px

border: 5px

El padding y el border están incluidos en los 300px.

Ancho final: 300px

¿box-sizing se hereda?

La propiedad box-sizing no se hereda de forma automática. Por eso, un elemento hijo mantiene su valor inicial (content-box) si no se especifica otra regla.

Padre: box-sizing: border-box; width: 300px

Hijo: width: 100%, sin declarar box-sizing. Se sale del padre.

Resultado: box-sizing no es una propiedad heredable.
